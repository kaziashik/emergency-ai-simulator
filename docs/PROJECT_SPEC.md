# PROJECT SPECIFICATION

## Project Name
EmergencyAI Simulator

## Objective
Develop an interactive building emergency simulation
with AI-assisted emergency decision support.

## Target Scenario
A simulated fire emergency inside a small building.

## Main Users
1. Simulation operator
2. Emergency decision-support AI

## Core Features

### Feature 1: Building Environment
- Create a simple 3D building.
- Include rooms and corridors.
- Add two emergency exits.
- Add a fire hazard area.

### Feature 2: People Simulation
- Add simulated people (NPCs).
- Display their positions.
- Allow movement toward exits.
- Display evacuation status.

### Feature 3: Emergency Monitoring
- Detect simulated fire locations.
- Track the number of people.
- Identify blocked exits.
- Collect basic emergency information.

### Feature 4: AI Decision Support
- Assess emergency severity.
- Identify available exits.
- Recommend evacuation routes.
- Explain recommendations.

### Feature 5: Human-in-the-Loop
- Display AI recommendations.
- Allow an operator to approve or reject them.
- Record the operator's decision.

## MVP Success Criteria

- Unity environment runs.
- Simulated people can move.
- Emergency information reaches the backend.
- AI returns a structured recommendation.
- Operator can approve or reject a recommendation.
- The complete workflow can be demonstrated.

## Limitations

This is a prototype for research and demonstration.
It must not be represented as a validated
fire safety or emergency response system.
